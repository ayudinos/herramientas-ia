# 🛠️ Buscador Maestro de Herramientas para Desarrolladores

> ℹ️ **Nota sobre el proyecto:** Este buscador es un **fork** (una versión derivada y traducida) del increíble proyecto original [free-for-dev](https://github.com/ripienaar/free-for-dev) de R. Pienaar. Mi objetivo es facilitar el acceso a estos recursos a la comunidad hispanohablante.

Bienvenido al catálogo completo. Usa la barra de búsqueda para encontrar cualquier servicio gratuito por nombre o categoría.

## ☁️ Proveedores de Nube (Cloud)
* **[Google Cloud Platform](https://cloud.google.com/free/)**: Capa gratuita de uso de por vida y $300 en créditos iniciales.
* **[Amazon Web Services (AWS)](https://aws.amazon.com/free/)**: 12 meses gratis en servicios populares como EC2 y S3.
* **[Microsoft Azure](https://azure.microsoft.com/free/)**: Capas gratuitas y $200 de crédito inicial.
* **[Oracle Cloud](https://www.oracle.com/cloud/free/)**: El mejor "Siempre Gratis" con potentes instancias ARM.
* **[IBM Cloud](https://www.ibm.com/cloud/free)**: Acceso a Watson IA y contenedores.

## 📦 Alojamiento de Código (Repositorios)
* **[GitHub](https://github.com/)**: Repositorios públicos/privados ilimitados y GitHub Actions.
* **[GitLab](https://about.gitlab.com/)**: Repositorios ilimitados con 400 min de CI/CD gratuitos.
* **[Bitbucket](https://bitbucket.org/)**: Gratis para hasta 5 usuarios.
* **[Codeberg](https://codeberg.org/)**: Hosting Git libre y sin fines de lucro basado en Gitea.

## 🚀 Hosting y Despliegue (PaaS)
* **[Vercel](https://vercel.com/)**: Especialista en Next.js y apps estáticas.
* **[Netlify](https://www.netlify.com/)**: Ideal para sitios estáticos y funciones serverless.
* **[Render](https://render.com/)**: Despliega Node, Python, Rust y Go gratis.
* **[Fly.io](https://fly.io/)**: Despliega apps cerca de tus usuarios con una capa gratuita por uso.
* **[Railway](https://railway.app/)**: Hosting rápido con créditos gratuitos mensuales (limitado).

## 💾 Bases de Datos (DBaaS)
* **[MongoDB Atlas](https://www.mongodb.com/cloud/atlas)**: Base de datos NoSQL líder con 512MB gratis.
* **[Supabase](https://supabase.com/)**: El Firebase de código abierto (PostgreSQL).
* **[PlanetScale](https://planetscale.com/)**: MySQL escalable para flujo de trabajo moderno.
* **[Upstash](https://upstash.com/)**: Redis, Kafka y Vector DB sin servidor.
* **[CockroachDB](https://www.cockroachlabs.com/pricing/free/)**: Base de datos SQL distribuida gratuita.

## 🤖 Inteligencia Artificial y ML
* **[Hugging Face](https://huggingface.com/)**: El "GitHub" de la IA. Modelos y datasets.
* **[Google Colab](https://colab.research.google.com/)**: Cuadernos Jupyter con acceso a GPU.
* **[Pinecone](https://www.pinecone.io/pricing/)**: Base de datos de vectores para aplicaciones de IA.
* **[Kaggle](https://www.kaggle.com/)**: Entornos de ML y datasets gratuitos.

## 🔍 Herramientas de API y Datos
* **[Postman](https://www.postman.com/)**: Plataforma para pruebas de API con capa gratuita.
* **[Airtable](https://airtable.com/)**: Mezcla de base de datos y hoja de cálculo.
* **[Citus Cloud](https://www.citusdata.com/product/cloud)**: PostgreSQL escalable para análisis rápido.

## 📧 Correo Electrónico (Mailing y Transaccional)
* **[SendGrid](https://sendgrid.com/solutions/email-api/pricing/)**: 100 correos al día gratis para siempre.
* **[Brevo (Sendinblue)](https://www.brevo.com/es/pricing/)**: 300 correos al día con contactos ilimitados.
* **[MailerLite](https://www.mailerlite.com/es/pricing)**: Gratis hasta 1,000 suscriptores y 12,000 correos al mes.
* **[Resend](https://resend.com/pricing)**: La mejor API para desarrolladores, 3,000 correos al mes gratis.
* **[Mailtrap](https://mailtrap.io/)**: Servidor SMTP falso para probar envíos en desarrollo sin spam real.

## 📈 Análisis y Métricas
* **[Google Analytics](https://analytics.google.com/)**: El estándar para medir tráfico web gratis.
* **[Umami](https://umami.is/)**: Alternativa a Google Analytics, de código abierto y enfocada en la privacidad.
* **[Mixpanel](https://mixpanel.com/pricing/)**: Gratis hasta 20 millones de eventos al mes.
* **[Hotjar](https://www.hotjar.com/pricing/)**: Mapas de calor y grabaciones de usuarios (capa gratuita básica).
* **[Amplitude](https://amplitude.com/pricing)**: Análisis de producto avanzado con 10 millones de eventos mensuales.

## 🔐 Seguridad y Autenticación
* **[Auth0](https://auth0.com/pricing)**: Autenticación para hasta 7,500 usuarios activos mensuales.
* **[Clerk](https://clerk.com/pricing)**: Gestión de usuarios para React/Next.js (capa gratuita muy generosa).
* **[Cloudflare](https://www.cloudflare.com/es-es/plans/)**: Protección contra DDoS, CDN y SSL gratuito.
* **[Snyk](https://snyk.io/plans/)**: Escaneo de vulnerabilidades en tu código y dependencias.
* **[Bitwarden](https://bitwarden.com/pricing/)**: Gestor de contraseñas de código abierto ilimitado para uso personal.

## 📝 CMS (Gestores de Contenido)
* **[Contentful](https://www.contentful.com/pricing/)**: CMS "Headless" líder con capa gratuita para proyectos pequeños.
* **[Strapi](https://strapi.io/pricing-cloud)**: CMS de código abierto basado en Node.js (opción self-hosted gratis).
* **[Sanity.io](https://www.sanity.io/pricing)**: Generoso plan gratuito con usuarios ilimitados para proyectos personales.
* **[Ghost](https://ghost.org/)**: Si lo instalas tú mismo es gratis; plataforma enfocada en blogs y newsletters.

## 🖼️ Gestión de Imágenes y Media
* **[Cloudinary](https://cloudinary.com/pricing)**: Gestión de imágenes y video con transformación automática (capa gratuita por créditos).
* **[Imgix](https://www.imgix.com/pricing)**: Optimización de imágenes en tiempo real.
* **[Uploadcare](https://uploadcare.com/pricing/)**: Manipulación y carga de archivos con CDN integrado.

## 🎨 Diseño y UI/UX
* **[Figma](https://www.figma.com/pricing/)**: La herramienta líder de diseño colaborativo. Gratis para 3 archivos y proyectos personales.
* **[Canva](https://www.canva.com/pricing/)**: Diseño gráfico sencillo con miles de plantillas gratuitas.
* **[Font Awesome](https://fontawesome.com/plans)**: El set de iconos más usado del mundo con miles de iconos gratuitos.
* **[Google Fonts](https://fonts.google.com/)**: Catálogo inmenso de tipografías gratuitas para uso comercial y personal.
* **[Spline](https://spline.design/pricing)**: Herramienta de diseño 3D para la web con capa gratuita.
* **[Excalidraw](https://excalidraw.com/)**: Pizarra virtual de código abierto con estilo de dibujo a mano.

## 🐞 Registro de Errores y Logs (Monitoring)
* **[Sentry](https://sentry.io/pricing/)**: Monitorización de errores en tiempo real. Gratis para proyectos pequeños (5,000 eventos/mes).
* **[Log DNA](https://www.mezmo.com/pricing)**: Gestión de logs avanzada con capa gratuita de búsqueda.
* **[Better Stack](https://betterstack.com/pricing)**: Gestión de logs y páginas de estado (Status Pages) gratuitas.
* **[Datadog](https://www.datadoghq.com/pricing/)**: Monitorización de infraestructura (capa gratuita limitada para pocos nodos).
* **[New Relic](https://newrelic.com/pricing)**: 100 GB de datos al mes gratuitos para monitorización completa.

## 🧪 Testing y Calidad de Código
* **[SonarCloud](https://www.sonarsource.com/products/sonarcloud/pricing/)**: Análisis de seguridad y calidad de código gratuito para proyectos Open Source.
* **[BrowserStack](https://www.browserstack.com/open-source)**: Pruebas en navegadores reales gratuitas para proyectos de código abierto.
* **[Cypress](https://www.cypress.io/pricing)**: Testing de extremo a extremo (E2E) con dashboard gratuito para equipos pequeños.
* **[LambdaTest](https://www.lambdatest.com/pricing)**: Pruebas de compatibilidad entre navegadores en la nube.

## 💬 Comunicaciones y Colaboración
* **[Slack](https://slack.com/pricing)**: La plataforma de mensajería para equipos con historial de 90 días gratuito.
* **[Discord](https://discord.com/nitro)**: Chat de voz y texto ilimitado, ideal para comunidades de desarrolladores.
* **[Trello](https://trello.com/pricing)**: Gestión de proyectos mediante tableros visuales (10 tableros gratis).
* **[Zoom](https://zoom.us/pricing)**: Videollamadas gratuitas de hasta 40 minutos (para grupos).

## 🌍 Dominios y DNS
* **[Freenom](http://www.freenom.com/)**: Dominios gratuitos (.tk, .ml, .ga) - *Nota: revisar disponibilidad por región*.
* **[Cloudflare DNS](https://www.cloudflare.com/es-es/dns/)**: El servicio de DNS más rápido y seguro con capa gratuita de protección.
* **[DuckDNS](https://www.duckdns.org/)**: Servicio de DNS dinámico gratuito.

## 💳 Pagos y Facturación
* **[Stripe](https://stripe.com/pricing)**: La mejor infraestructura de pagos. Sin costos mensuales, solo pagas por transacción.
* **[PayPal Developer](https://developer.paypal.com/)**: Integración de pagos global con un entorno de pruebas (sandbox) muy robusto.
* **[Lemon Squeezy](https://www.lemonsqueezy.com/pricing)**: Merchant of Record que gestiona impuestos por ti. Sin cuotas fijas.
* **[Paddle](https://www.paddle.com/pricing)**: Otra excelente opción para vender software globalmente sin preocuparte por el IVA internacional.

## 🔍 Motores de Búsqueda (Search as a Service)
* **[Algolia](https://www.algolia.com/pricing/)**: El buscador más rápido del mundo. Capa gratuita generosa para proyectos pequeños.
* **[Meilisearch](https://www.meilisearch.com/pricing)**: Alternativa de código abierto a Algolia, ultra rápida y fácil de desplegar.
* **[Searchisko](https://searchisko.org/)**: Motor de búsqueda basado en Elasticsearch especializado en contenido de comunidades.

## 🔔 Notificaciones y Mensajería (Push/SMS)
* **[OneSignal](https://onesignal.com/pricing)**: Notificaciones push ilimitadas para móviles y web (capa gratuita muy amplia).
* **[Pusher](https://pusher.com/pricing)**: Mensajería en tiempo real mediante WebSockets. Gratis hasta 200,000 mensajes diarios.
* **[Ably](https://ably.com/pricing)**: Infraestructura Pub/Sub para experiencias en tiempo real con 6 millones de mensajes mensuales gratis.
* **[Courier](https://www.courier.com/pricing/)**: Una sola API para gestionar Push, Email, Slack y SMS. 10,000 mensajes gratis al mes.

## 💻 IDEs y Editores de Código
* **[Visual Studio Code](https://code.visualstudio.com/)**: El editor estándar de la industria, totalmente gratuito y extensible.
* **[JetBrains (Community)](https://www.jetbrains.com/opensource/)**: Versiones gratuitas de IntelliJ IDEA y PyCharm para desarrollo Java y Python.
* **[Cursor](https://www.cursor.com/)**: El primer editor de código construido específicamente para programar con IA (basado en VS Code).
* **[CodeSandbox](https://codesandbox.io/pricing)**: Editor en la nube ideal para prototipar aplicaciones web rápidamente.

## 📊 Visualización de Datos y Dashboards
* **[Grafana](https://grafana.com/pricing/cloud/)**: Visualización de métricas y logs con un plan gratuito en la nube muy completo.
* **[Metabase](https://www.metabase.com/pricing/)**: La forma más fácil de que todos en tu equipo hagan preguntas sobre los datos (Open Source gratis).
* **[Tableau Public](https://public.tableau.com/en-us/s/)**: Crea y comparte visualizaciones de datos interactivas de forma pública.

## 🛠️ Túneles y Desarrollo Local (Localhost to Web)
* **[Ngrok](https://ngrok.com/pricing)**: La herramienta clásica para exponer tu servidor local a internet. Capa gratuita para 1 túnel.
* **[LocalXpose](https://localxpose.io/)**: Alternativa a Ngrok con una interfaz sencilla y reglas personalizadas.
* **[Cloudflare Tunnel](https://www.cloudflare.com/products/tunnel/)**: Conecta de forma segura tu servidor local a la red de Cloudflare gratis.
* **[Telebit](https://telebit.cloud/)**: Túneles con soporte para múltiples protocolos y certificados automáticos.

## 🌉 Gestión y Diseño de APIs (API Management)
* **[Swagger / OpenAPI](https://swagger.io/tools/swaggerhub/pricing/)**: Diseña y documenta tus APIs con un editor visual potente.
* **[Beeceptor](https://beeceptor.com/)**: Crea un endpoint de API falso (mock) en segundos para pruebas.
* **[Mockoon](https://mockoon.com/)**: Aplicación de escritorio gratuita para simular APIs locales sin servidor.
* **[Hopper](https://hoppscotch.io/)**: Alternativa a Postman, ligera, rápida y de código abierto.

## 📱 Desarrollo Móvil
* **[Expo](https://expo.dev/pricing)**: La mejor forma de crear apps con React Native. Capa gratuita para construcción y actualizaciones.
* **[AppCenter (Microsoft)](https://appcenter.ms/)**: Automatización de compilaciones y distribución de apps móviles.
* **[RevenueCat](https://www.revenuecat.com/pricing)**: Gestiona compras in-app y suscripciones fácilmente. Gratis hasta 10k de ingresos mensuales.

## 🌐 Redes y VPN (Networking)
* **[Tailscale](https://tailscale.com/pricing)**: Crea una red privada virtual (VPN) entre tus dispositivos de forma increíblemente fácil.
* **[ZeroTier](https://www.zerotier.com/pricing/)**: Conecta tus computadoras como si estuvieran en el mismo cable de red, gratis hasta 25 nodos.

## 📜 Otros Recursos Útiles
* **[Carbon](https://carbon.now.sh/)**: Crea imágenes preciosas de tus fragmentos de código para compartir.
* **[SmallDev.tools](https://smallprivatetools.com/)**: Una colección masiva de herramientas: formateadores de JSON, codificadores Base64, etc.
* **[Can I Use](https://caniuse.com/)**: Verifica la compatibilidad de funciones CSS/JS en diferentes navegadores.

### ¿Cómo mantenerlo?
1. **Actualiza:** Si descubres una herramienta nueva, solo añade una línea con el formato `* **[Nombre](URL)**: Descripción`.
2. **Personaliza:** Puedes cambiar los colores en el `index.html` editando el tema de Docsify.
3. **Comparte:** Tu enlace ya es público: `https://ayudinos.github.io/herramientas-ia/`
