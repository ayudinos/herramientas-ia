# 🛠️ Buscador de Herramientas para Desarrolladores (IA)

Bienvenido a esta base de conocimientos. Esta es una lista curada de servicios de software (SaaS, PaaS, IaaS, etc.) que tienen **capas gratuitas** para desarrolladores.

> **Instrucciones:** Usa la barra de búsqueda de la izquierda (o la lupa) para filtrar por tecnologías. Por ejemplo: "Hosting", "Cloud", "Database".

---

## ☁️ Principales Proveedores de la Nube (Cloud)

* **[Google Cloud Platform](https://cloud.google.com/free/)**: Ofrece una capa gratuita de "uso de por vida" y $300 en créditos para nuevos usuarios.
* **[Amazon Web Services (AWS)](https://aws.amazon.com/free/)**: Ofrece varios servicios gratuitos durante 12 meses, incluyendo instancias EC2 pequeñas.
* **[Microsoft Azure](https://azure.microsoft.com/free/)**: Capas gratuitas de por vida y $200 de crédito inicial.
* **[Oracle Cloud](https://www.oracle.com/cloud/free/)**: Incluye instancias ARM potentes y bases de datos autónomas siempre gratuitas.
* **[IBM Cloud](https://www.ibm.com/cloud/free)**: Acceso gratuito a servicios de IA (Watson), contenedores y bases de datos.

---

## 📦 Repositorios de Código Fuente

* **[GitHub](https://github.com/)**: Repositorios públicos y privados ilimitados gratuitos. Acceso a GitHub Actions (CI/CD).
* **[GitLab](https://about.gitlab.com/pricing/)**: Repositorios ilimitados y minutos de CI gratuitos.
* **[Bitbucket](https://bitbucket.org/product/pricing)**: Gratuito para hasta 5 usuarios con repositorios privados ilimitados.

---

## 🚀 Hosting y Despliegue (PaaS)

* **[Vercel](https://vercel.com/)**: El mejor para despliegue de aplicaciones Next.js y estáticas.
* **[Netlify](https://www.netlify.com/)**: Excelente para hosting de sitios estáticos con funciones Serverless gratuitas.
* **[Cloudflare Pages](https://pages.cloudflare.com/)**: Hosting estático rápido con ancho de banda ilimitado.
* **[Render](https://render.com/)**: Hosting gratuito para servicios web (Node, Python, Go) y bases de datos PostgreSQL (por tiempo limitado).

---

## 💾 Bases de Datos como Servicio

* **[MongoDB Atlas](https://www.mongodb.com/cloud/atlas)**: Cluster gratuito de 512MB de NoSQL.
* **[PlanetScale](https://planetscale.com/)**: Base de datos MySQL con escalabilidad increíble (Capa gratuita limitada).
* **[Supabase](https://supabase.com/)**: Alternativa a Firebase con PostgreSQL, autenticación y tiempo real.
* **[Upstash](https://upstash.com/)**: Redis y Kafka sin servidor con capa gratuita por uso.

---

## 🤖 Inteligencia Artificial y Machine Learning

* **[OpenAI API](https://openai.com/api/)**: Ofrece créditos gratuitos limitados para nuevos usuarios para probar GPT.
* **[Hugging Face](https://huggingface.com/)**: Hosting de modelos y datasets de IA de código abierto.
* **[Google Colab](https://colab.research.google.com/)**: Entorno de Jupyter Notebook con GPU gratuita (limitada).
